# Senior Product Designer Portfolio

A modern, minimal, and creative portfolio website designed specifically for senior product designers. This portfolio showcases professional work with elegant animations, responsive design, and a focus on user experience.

## 🎨 Design Features

- **Minimal & Clean**: Focus on content with plenty of whitespace
- **Creative Elements**: Subtle animations and interactive components
- **Professional Typography**: Using Inter font family for modern readability
- **Responsive Design**: Optimized for all devices and screen sizes
- **Accessibility**: WCAG compliant with proper focus states and keyboard navigation

## 🚀 Key Features

### Visual Design
- Gradient accents and floating elements
- Smooth scroll animations
- Hover effects and micro-interactions
- Progress bar indicator
- Parallax scrolling effects

### User Experience
- Fixed navigation with backdrop blur
- Smooth scrolling between sections
- Mobile-friendly hamburger menu
- Touch gesture support
- Loading animations

### Content Sections
- **Hero Section**: Compelling introduction with call-to-action buttons
- **Work Portfolio**: Showcase of selected projects with categories and tags
- **About Section**: Professional background and core skills
- **Contact Section**: Multiple ways to get in touch

## 🎯 Customization Guide

### Colors
The portfolio uses CSS custom properties for easy color customization:

```css
:root {
    --primary-color: #2d3436;
    --secondary-color: #636e72;
    --accent-color: #00b894;
    --background-color: #ffffff;
    --surface-color: #f8f9fa;
    --text-primary: #2d3436;
    --text-secondary: #636e72;
}
```

### Content Updates
1. **Personal Information**: Update name, title, and contact details in `index.html`
2. **Work Projects**: Replace placeholder content with actual project details
3. **Skills**: Modify the skills section to match your expertise
4. **Social Links**: Update social media URLs in the contact section

### Adding Real Images
Replace the placeholder elements with actual project images:

```html
<div class="work-image">
    <img src="path/to/your/project-image.jpg" alt="Project description">
</div>
```

### Local Development

To run the portfolio locally:

1. Open `index.html` in a web browser
2. Or use a local server:
   ```bash
   # Using Python
   python -m http.server 8000
   
   # Using Node.js
   npx serve .
   ```

## 🎨 Design Principles

This portfolio follows these design principles:

1. **Minimalism**: Less is more - focus on content over decoration
2. **Typography**: Clear hierarchy and readable fonts
3. **Whitespace**: Generous spacing for better readability
4. **Consistency**: Unified design language throughout
5. **Accessibility**: Inclusive design for all users
